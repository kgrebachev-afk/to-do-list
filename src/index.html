Entrée

Retrouver vos tâches de l'ordinateur

Sur l'ordinateur : Réglages, « Synchroniser mes appareils », un QR code s'affiche. Scannez-le ici pour avoir la même liste, et recevoir les rappels en notification même application fermée.

Installer To do list sur cet ordinateur

L'application s'ouvrira dans sa propre fenêtre, avec son icône dans la barre des tâches, et fonctionnera même sans réseau. Une fois installée, Chrome garde l'accès à votre fichier de sauvegarde : plus de sauvegarde en pause.

Touchez le bouton Partager de Safari (le carré avec une flèche vers le haut), puis « Sur l'écran d'accueil ». Ouvrez ensuite To do list depuis son icône : c'est nécessaire pour recevoir les notifications.

Activer la sauvegarde automatique

Choisissez une seule fois où enregistrer vos tâches, de préférence dans votre dossier OneDrive. Ensuite, chaque modification y est enregistrée toute seule : rien à cliquer, ni à la fermeture, ni à l'ouverture.

    Pourquoi un rappel peut arriver en retard

    Les rappels partent tant que la page est ouverte dans Chrome, même en arrière-plan ou fenêtre réduite. Si Chrome est fermé, ou si Chrome a désactivé l'onglet pour économiser la mémoire, le rappel s'affiche dès que vous revenez sur la page, avec son retard indiqué.

    Le plus simple : épinglez l'onglet (clic droit sur l'onglet, puis Épingler). Chrome ne désactive jamais un onglet épinglé. Autre solution : dans Chrome, Paramètres, Performances, puis ajoutez cette page à Toujours garder ces sites actifs. Pour un rappel qui ne doit jamais être manqué, même Chrome fermé, utilisez Ajouter à Outlook dans le détail de la tâche.
